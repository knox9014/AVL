# AVL v1 사용법

[English](USAGE.md) | [한국어](USAGE.ko.md)

AVL v1은 지원 범위를 정한 영어 의미 송수신 인터페이스입니다.
임의의 자연어를 이해하는 범용 분석기는 아닙니다.
[사전 명세](AVL_V1_PROTOCOL.md)에 문법·항목·학습 예산·성공 관문을 기록했습니다.

## 실행

PyTorch를 설치한 뒤 저장소 루트에서 실행합니다.

```bash
python -m antlab.semantic_demo --text "When it rains, it is possible that the door is not closed." --text "Please make sure that the budget limit is at most 20 USD."
```

`--text` 하나가 사용자가 직접 나눈 구간 하나입니다. 긴 글을 자동으로
분할하거나 요약하는 기능은 아직 없습니다. 송신자는 원문을 로컬에 보존하고
지원 문법에 맞는지 참/거짓만 검사합니다. 이 검사로 의미 정답을 제공하지는
않습니다. 대소문자·공백은 학습과 동일하게 정규화합니다.

수신자는 패킷 바이트만 받아 요청/사실·대상·술어·부정·불확실성·조건·금액·
비교 조건·단위를 예측합니다. 원문·정답·지원 여부는 받지 않습니다.
구간2개는 벡터128바이트와 헤더12바이트로 총140바이트입니다.

미지원 입력은 원문과 `unsupported` 상태로 유지하며 임의로 해석하지 않습니다.
벡터 자체가 개인정보를 익명화하는 것은 아닙니다.

## 검증과 재학습

```bash
python -m unittest discover -s antlab/tests
python -m antlab.semantic_run --output antlab/runs/semantic-v1-20261006 --verify
python -m antlab.semantic_run --output antlab/runs/my-new-study
```

새 실험은 시드3개·각1,500스텝으로 실행하며 출력 폴더는 새 경로여야 합니다.
검증은 복원 모델의 실제 바이트 송수신 결과와 데이터·소스·기록 해시,
학습 메타데이터를 다시 확인합니다. 학습을 재실행하지는 않습니다.
기본 시드11은 시험 전에 정했으며 시험 최고 모델을 고른 것이 아닙니다.
환경에 따라 부동소수점 결과가 달라질 수 있습니다.

## 범위

램프·히터·선풍기·문·예산의 정해진 문법을 지원합니다. 금액은10/20/50/100 USD입니다.
17 USD·새 대상·중첩 조건·다른 문법은 미지원으로 처리합니다.
부정은 원래 술어를 부정한 채 유지하고 반대 상태를 추론하지 않습니다.
가능성과 확정 상태를 구분하며 조건은 구간 하나 전체에 적용됩니다.
짧은 원문보다 벡터가 클 수도 있으므로 의미 보존과 압축 효율은 별도로 평가합니다.
기존 v0의50% 실패 기록은 보존합니다.
v1도 사전 성공 기준을 통과하지 못했습니다. 지원 문법에 맞는 입력도
새로운 표현에서는 잘못 판독할 수 있습니다. [결과](AVL_V1_RESULTS.md)를 참고하세요.
