# 영어 입출력 연결 몸체 v0 결과

실행 시작 2026-10-05, 최종 정리 2026-10-06. [구조 명세](2026-10-05-english-connected-body.md). 실행 기록: `antlab/runs/english-body-smoke-20261005/`.

## 구현

98,928개의 고유 파라미터를 공유하는 유닛 몸체를 구현했다. 지역 영어 문자 입력을 GRU 상태로 만들고, 16차원 벡터를 동료에게 보내며, 수신 정보를 공유 GRUCell로 계산에 섞는다. 지정 출력 유닛의 상태에서 문자 GRU가 영어 문자를 생성한다. 유닛마다 입력·상태만 분리하며 가중치는 공유한다.

```mermaid
flowchart LR
    A[유닛별 영어 입력] --> B[공유 입력 인코더]
    B --> C[유닛별 지역 상태]
    C --> D[공유 송신기: 벡터16개]
    D --> E[동료 메시지 수신과 상태 갱신]
    E --> D
    E --> F[지정 유닛의 영어 출력]
```

N=1/2/4/8의 형태·파라미터 수, 패딩 불변성, 통신 차단, 동기/직렬 동등성, 유닛 순열, 경사 경로, BOS·자기 출력 되먹임·배치별 EOS 종료를 검사했다. 3유닛 경사 테스트에서는 query/key 경로도 검사한다. 다음 2유닛 smoke에서는 동료가 하나라 attention 선택을 학습하는 실험은 아니다.

## 실제 학습: 동료 정보 활용 실패

출력 유닛은 `Is the lamp on?`을 읽고 동료 유닛은 `The lamp is on/off.`를 읽는다. 기대 출력은 `YES/NO + EOS`다. 고정한 문장 조합12개로 시드105, AdamW400스텝을 학습했다. 별도 문장 변형8개는 학습·모델 선택에 쓰지 않았다. 결과를 보고 추가 학습이나 설정 튜닝을 하지 않았다.

| 평가 조건 | 학습 문장12개 | 별도 문장 변형8개 |
|---|---:|---:|
| 연결 | 6/12, 50% | 4/8, 50% |
| 통신 차단 | 6/12, 50% | 4/8, 50% |
| 동료 사실 on/off 교체, 교체 정답으로 채점 | 6/12, 50% | 4/8, 50% |
| 차단 상태에서 동료 사실 교체 | 6/12, 50% | 4/8, 50% |
| 같은 snapshot의 직렬 실행 | 6/12, 50% | 4/8, 50% |

모든 입력에서 실제 생성 결과가 `YES + EOS`였다. 평가는 BOS부터 생성한 전체 토큰 시퀀스를 정답과 비교했으며, 생성에 정답 문자나 teacher forcing 입력을 주지 않았다. 동료 사실 교체로 바뀐 답은0개였다.

최종 학습 로그 loss는 약0.197이다. 공통 문자 형식을 예측하면서 정답 분기를 무시해도 전체 문자 손실이 낮아질 수 있으므로, 낮은 손실만으로 통신 학습을 주장할 수 없다. 확인된 것은 입출력·경사·학습·저장·복원 파이프라인이며, 이번 실행은 유용한 통신 학습이나 범용 영어 이해에 성공하지 못했다.

## 사후 관찰

별도 `antlab/runs/english-body-posthoc-20261005.json`은 저장 가중치를 바꾸지 않고 학습 문장의 off/on 쌍을 비교한 사후 진단이다. 첫 라운드 동료 메시지의 최대 좌표 차이는 약0.288인데, 출력 유닛 최종 상태 차이는 약8.8e-5, 첫 출력 문자 logit 차이는 약1.4e-6이다. 두 경우 모두 첫 문자에서 YES가 NO보다 높은 점수를 받았다.

입력 변화가 메시지를 바꾸기는 하지만 최종 답을 바꾸지 못했다는 관찰이다. 벡터의 의미를 해독하거나 실패 원인을 확정한 인과 실험은 아니다. 다음에는 학습 입력만으로 지역 인코더·수신 갱신·출력부의 정보 보존을 각각 검사하고 새 실험 예산을 미리 고정해야 한다.

현재는 학습 가능한 내부 통신 채널 단계다. 범용적인 새 언어인지, 짧은 텍스트나 이산 표현보다 효율적인지는 아직 입증하지 않았다. float32 벡터 한 메시지는64바이트이고, 두 유닛·두 라운드에서는 샘플당 논리적 전송량256바이트다. 실제 네트워크 헤더·복사·지연을 측정한 값은 아니다. 이 단순 이진 사실에 벡터가 더 저렴하다는 근거는 없다.

저장 소스·데이터·체크포인트 해시와 초기 가중치 대비 업데이트 기록을 검사하고, 복원 모델의 생성으로10개 조건을 다시 확인한다. 검증 결과는 `status=complete, smoke_only=true, verified_conditions=10, train_accuracy=0.5, heldout_accuracy=0.5`다. complete는 기록·재현의 완료이며 능력 관문 통과를 뜻하지 않는다.

ACT 원본 작업 공간에서는 전체 연구 테스트145개가 통과했다. 이 AVL 저장소에는 영어 몸체 테스트6개와 smoke/기록 검증 테스트6개를 선별했다.

최종 목표인 연결 수에 따른 범용 능력 향상은 미입증이다. 이 smoke는 N 증가나 미학습 과제 일반화 평가를 대체하지 않는다. 이전 그래프 진단은 이 AVL 저장소의 실험 범위에 포함하지 않는다.
