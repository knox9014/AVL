# 영어 입출력 공유 신경망 몸체 v0

2026-10-05. 사용자 요청: 압축 검토를 뒤로 미루고 신경망 개발을 이어간다. 최종 목표는 동일 유닛의 연결 수가 늘어날수록 여러 분야의 능력이 향상되는 범용 AI다. 영어를 첫 입출력 언어로 사용한다. 이 문서는 연결 몸체를 구현하는 범위이며 범용 능력을 학습·입증했다는 주장이 아니다.

## 구현 결정

기존 99,848파라미터 CompactFrontier는 그래프 실행 진단으로 마무리한다. 영어 몸체는 별도 모듈로 만든다. 기존 체크포인트와 모델의 동작을 바꾸지 않는다.

새 몸체는 ASCII 영어 문자 임베딩(128종,48차원), 지역 입력 GRU(64상태), 송신기(64→16), 수신 attention(query64→16,key16→16), 수신 투영(16→64), 공유 GRUCell(입력128,상태64), 문자 출력 GRU(48→64)와 출력층(64→128)으로 구성한다. 고유 파라미터 수는 98,928개다. N개의 유닛은 같은 가중치를 참조하며 각각 별도 상태를 갖는다.

메시지는 압축하지 않은 float32 벡터16개다. 수신자가 참조하는 동료 정보는 이 메시지뿐이다. 동료 hidden state를 attention key 등으로 몰래 사용하지 않는다. 자기 query와 받은 메시지의 key를 사용하며 self 수신은 제외한다. 지정 출력 유닛은 자기 최종 상태에서만 답변을 생성한다. 새 패킷 규약이나 인터넷 통신은 이번 범위가 아니다.

지역 영어 입력은 [B,N,L] 문자 ID와 실제 길이다. 패딩은0, 시작1, 끝2, 일반 ASCII 문자는 원래 코드값이다. 길이를 이용해 패딩이 인코더 상태에 영향을 주지 않게 한다. 요청은 각 유닛의 지역 텍스트에 포함할 수 있다. 유닛마다 입력·상태가 달라져도 가중치는 같으며 learned node-ID 임베딩은 사용하지 않는다.

동기 업데이트: 라운드 시작 상태에서 모든 메시지를 만들고, 그 snapshot에서 다음 상태를 계산한다. blocked는 수신을0으로 차단한다. serial은 동일한 snapshot으로 유닛별 계산을 순차 실행하는 대조군이다. 기본2라운드, 0라운드 지역-only 검사도 지원한다. serial과 connected의 계산량·결과 동등성은 구현 검증이며 지능 향상의 증거가 아니다.

출력 학습은 teacher forcing의 이전 문자 입력을 사용할 수 있다. 실제 generate에는 정답 문자 입력을 주지 않고 BOS에서 시작해 모델의 출력만 되먹임한다. EOS 또는 길이 제한에서 멈춘다. 이 몸체가 영어를 이해한다고 가정하지 않는다.

## 구현·검증 순서

1. 테스트 먼저: 파라미터98,928/N별공유, shape, padding 불변성, 자기/동료 경사 경로, blocked/0round 원격 불변성, connected/serial 일치, 유닛 순열+출력 위치 교환, 실제 생성 경로.
2. 최소 몸체와 ASCII 입력 함수 구현. 학습 데이터/정답은 forward 통신 경로에 넣지 않는다.
3. 작은 두-unit 영어 YES/NO smoke 과제로 gradient·학습·저장/복원 경로를 확인한다. 같은 문장 형식 안의 smoke 학습을 영어 이해나 새로운 과제 일반화로 부르지 않는다. 원격 정보를 사용하지 못했으면 그 결과도 그대로 남긴다.
4. 기존 compact 사전 프로토콜의 학습과 그래프 재평가를 진행하고 별도 결과로 기록한다.

## 다음 실험에 필요한 조건

범용성 평가는 이후 다양한 과제 유형의 공동 학습, 미학습 조합/과제 유형 평가, N1/2/4/8 및 미학습 N, 전체 정보 단독 모델, 동일 총 연산/기억의 직렬 대조군, 메시지 교란을 포함하도록 별도로 고정한다. 이번 smoke는 그 평가를 대체하지 않는다. 논리식 의미를 직접 처리하는 엔진과 학습된 기호 언어는 이번 구현에서 추가하지 않는다.
