# AVL — AI Vector Language

[English](README.md) | [한국어](README.ko.md)

AVL은 AI 유닛 사이에서 유용한 의미를 보존하며 전달하는 벡터 통신을 연구합니다. 같은 가중치를 사용하는 신경망 유닛들이 전달받은 정보를 여러 과제에 활용하도록 만드는 것이 장기 목표입니다. 의미 보존 성능과 자원 비용을 함께 검증합니다.

**현재 상태: 초기 연구 프로토타입입니다.** 모델은 공유 파라미터98,928개와16차원 float32 메시지를 사용합니다. 각 유닛이 지역 영어 입력을 읽고 벡터를 교환한 뒤 문자를 생성할 수 있습니다. 그러나 첫 YES/NO 실험에서는 동료의 사실을 활용하지 못해 모든 입력에 `YES`를 출력했고, 정확도는50%였습니다. 유용한 범용 언어, 무손실 압축, 유닛 수 증가에 따른 지능 향상은 아직 입증하지 않았습니다.

## 포함된 내용

- 공유 입력 인코더·송신기·메시지 attention·상태 갱신기·문자 디코더.
- 동기 통신, 통신 차단, 같은 계산을 수행하는 직렬 대조군.
- 관련 테스트12개, 고정 예산의 재현 가능한 smoke 실행기와 체크포인트·소스 스냅샷.
- 합성 영어 원문·실제 벡터·원시 전송 바이트를 포함한 긴 입력 크기 측정.
- [의미 입력 설계](docs/SEMANTIC_INPUT.md), [몸체 설계](docs/research/2026-10-05-english-connected-body.md), [학습 결과](docs/research/2026-10-05-english-body-results.md), [긴 입력 측정](docs/research/2026-10-06-long-vector-size.md).

`antlab`은 기록된 소스 해시와 체크포인트 검증을 유지하기 위해 남겨 둔 기존 Python 모듈 이름입니다. 프로젝트 이름은 AVL입니다. 더 넓은 ACT 실험은 이 저장소에 포함하지 않습니다.

## 실행

Python3.10 이상과 PyTorch를 사용합니다. 기록된 실험은 PyTorch2.13, CPU 스레드2개로 실행했습니다. 아래 명령은 저장소 루트에서 실행합니다.

```bash
python -m pip install -r requirements.txt
python -m unittest discover -s antlab/tests
python -m antlab.english_connected_smoke --verify antlab/runs/english-body-smoke-20261005
python -m antlab.english_connected_smoke --output antlab/runs/my-smoke
python -m antlab.english_vector_size_probe --output antlab/runs/my-size-probe.json
```

출력 경로는 새 경로여야 하며 기존 기록을 덮어쓰지 않습니다. 검증은 소스·기록 해시를 확인하고 저장 체크포인트에서10개 평가 조건을 다시 계산합니다. PyTorch 버전이나 플랫폼이 다르면 부동소수점 결과가 달라질 수 있습니다. 엄격한 저장 기록 검증은 기록된 구현을 기준으로 합니다.

## 측정값의 의미

| 영어 원문 크기 | 벡터 하나의 크기 | 표현 크기 감소 |
|---:|---:|---:|
| 173바이트 | 64바이트 | 63.0% |
| 394바이트 | 64바이트 | 83.8% |
| 791바이트 | 64바이트 | 91.9% |
| 1,400바이트 | 64바이트 | 95.4% |

벡터 크기는 구조상 고정되어 있습니다. 이 수치는 **원문의 모든 의미가 보존됐다는 증거가 아닙니다.** 긴 입력의 on/off 쌍에서도 모델은 모두 `YES`라고 답했습니다. 두 유닛이 양방향으로 두 라운드 동안 메시지를 교환하면 샘플당 논리적 전송량은256바이트이며, 네트워크 부가 비용은 제외한 값입니다.
